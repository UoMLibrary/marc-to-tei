Repository and collection codes

The library code in 852 $b selects the repository and its collection-code lookup table:

  • JRLD → The John Rylands Library (about 90 collection codes, e.g. INCU → Incunable Collection, DANT → Dante Collection)
  • MLSC → Main Library Special Collections (about 65 collection codes, e.g. MAPC → Map Collection, GUAR → Guardian Archive Printed Collection)

The collection code from 852 $c is replaced with its full collection name when it exists in the selected table; unknown codes are passed through unchanged.

Relator terms

Contributor roles in 700 $e (e.g. editor, translator, former owner) are matched case-insensitively against the full MARC Code List for Relators (~250 terms) and emitted as a three-letter code in the role attribute of the resulting <editor> element. Unrecognised terms simply produce an <editor> without a role.

Template, fixed boilerplate and placeholders

Output follows the MDC TEI master template and carries its xml-model references to the cdcp.rng schema. Every file includes the template’s fixed values: the titleStmt responsibility statements, the publication statement (address, rights statements, CC BY-NC 4.0 licences with targets, publication date set to the year of conversion), the reader-availability statement, a digitisation custEvent with comment placeholders, and the LCSH, ISO 639-2, MARC relator, VIAF, TGN and AAT taxonomy declarations.

Skeleton elements are kept for cataloguers to complete after conversion: summary, material, dimensions, foliation, collation, condition, layoutDesc, handDesc, decoDesc (illustration and initial), additions, binding, provenance and acquisition. objectDesc/@form="codex" and supportDesc/@material="paper" are the template defaults and should be reviewed. Optional template modules with no MARC source (funder, altIdentifier, head, rubric/incipit/…, typeDesc, musicNotation, sealDesc, accMat, recordHist, msPart, projectDesc) are left out. VIAF, LCSH and TGN keys are deliberately emitted as zero-placeholders for a later authority-reconciliation pass.
