Repository and collection codes

The library code in 852 $b selects the repository and its collection-code lookup table:

  • JRLD → The John Rylands Library (about 90 collection codes, e.g. INCU → Incunable Collection, DANT → Dante Collection)
  • MLSC → Main Library Special Collections (about 65 collection codes, e.g. MAPC → Map Collection, GUAR → Guardian Archive Printed Collection)

The collection code from 852 $c is replaced with its full collection name when it exists in the selected table; unknown codes are passed through unchanged.

Relator terms

Contributor roles in 700 $e (e.g. editor, translator, former owner) are matched case-insensitively against the full MARC Code List for Relators (~250 terms) and emitted as a three-letter code in the role attribute of the resulting <editor> element. Unrecognised terms simply produce an <editor> without a role.

Fixed boilerplate and placeholders

Every output file carries the same publication statement (The University of Manchester Library / The John Rylands Library address, rights statements, CC BY-NC 4.0 licences), the LCSH and VIAF taxonomy declarations, and skeleton elements (handDesc, decoDesc, dimensions, foliation, …) intended to be completed by cataloguers after conversion. VIAF person keys and LCSH subject keys are deliberately emitted as zero-placeholders for a later authority-reconciliation pass.
